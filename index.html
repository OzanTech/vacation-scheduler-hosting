Vacation Scheduler

Vacation Scheduler is a native Android application for planning trips and excursions. Users can create vacations, attach excursions to each one, set date-based reminders, search and generate reports across their trip data, and secure the app behind a PIN — all backed by a local Room/SQLite database.

Download Signed APK

Minimum Android version: Android 8.0 (Oreo, API 26) or higher.

Key Features

  • Create, edit, and delete vacations and excursions
  • Search vacations by title
  • Combined vacation and excursion report with date-time stamp
  • PIN-protected access with securely hashed credentials
  • Database-backed, expandable excursion type selection
  • Scheduled local notifications for upcoming vacations and excursions
